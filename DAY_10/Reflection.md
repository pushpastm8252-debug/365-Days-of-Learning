## My Understanding

I understood that a class works like a blueprint, while an object is an instance of that class.

I learned that constructors are used to initialize object data.

I also learned how inheritance helps in code reuse and how polymorphism allows the same method name to behave differently.

Encapsulation helps in controlling access to data, while abstraction helps hide unnecessary implementation details.
