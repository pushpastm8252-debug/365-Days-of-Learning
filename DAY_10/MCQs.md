# ❓ Day 10 - Python OOP MCQs

# 🟢 Basic Level

### 1. What does OOP stand for?

A. Object-Oriented Programming  
B. Object-Operating Program  
C. Object-Order Programming  
D. Operating Object Program  

**Answer:** A

---

### 2. What is a class?

A. A variable  
B. A blueprint for objects  
C. A loop  
D. A function only  

**Answer:** B

---

### 3. What is an object?

A. Instance of a class  
B. Instance of a function  
C. A module  
D. A package  

**Answer:** A

---

### 4. Which keyword is used to create a class?

A. object  
B. class  
C. define  
D. struct  

**Answer:** B

---

### 5. Which method is commonly used as a constructor in Python?

A. `__start__()`  
B. `__create__()`  
C. `__init__()`  
D. `__newclass__()`  

**Answer:** C

---

### 6. What does `self` represent?

A. Parent class  
B. Current object  
C. Current module  
D. Current function  

**Answer:** B

---

### 7. Which decorator is used for a class method?

A. `@staticmethod`  
B. `@classmethod`  
C. `@classmethod()`  
D. `@method`  

**Answer:** B

---

### 8. Which decorator is used for a static method?

A. `@staticmethod`  
B. `@static`  
C. `@classmethod`  
D. `@method`  

**Answer:** A

---

### 9. Which concept allows one class to acquire properties of another class?

A. Encapsulation  
B. Inheritance  
C. Abstraction  
D. Compilation  

**Answer:** B

---

### 10. Which function is used to call the parent class implementation?

A. `parent()`  
B. `super()`  
C. `base()`  
D. `parent_class()`  

**Answer:** B
