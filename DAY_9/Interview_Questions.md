# 🎯 Interview Tips

- Learn all file modes (`r`, `w`, `a`, `x`, `r+`, `w+`, `a+`).
- Understand the difference between `read()`, `readline()`, and `readlines()`.
- Practice `try-except-finally` with real examples.
- Know how to create and import your own modules.
- Practice creating packages with `__init__.py`.
- Be familiar with common exceptions like `ZeroDivisionError`, `ValueError`, and `FileNotFoundError`.
- Practice file-based mini projects, as they are common in interviews.
