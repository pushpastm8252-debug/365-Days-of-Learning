# ⭐ Important Interview Question

## Flask vs FastAPI

A good answer:

> Flask is a lightweight and flexible Python web framework that can be used for both web applications and APIs. FastAPI is a modern framework focused strongly on API development and uses Python type hints for validation and automatic documentation. FastAPI is particularly useful when building modern API-based applications.
