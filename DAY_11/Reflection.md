## 💡 My Understanding

I learned that the `try` block contains code that may produce an exception.

The `except` block is used to handle the exception.

The `else` block runs when no exception occurs.

The `finally` block is normally executed whether an exception occurs or not.

The `raise` keyword allows us to manually raise an exception.
