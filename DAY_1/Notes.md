# 👋 Hello World Program

```python
print("Hello, World!")
```

### Output

```
Hello, World!
```

### Explanation

- `print()` displays output on the screen.
- `"Hello, World!"` is a string.
- Python prints everything written inside quotes.

# 🖥 print() Function

The `print()` function is used to display output on the screen.

### Syntax

```python
print("Message")
```

### Example

```python
print("Welcome")
```

Output

```
Welcome
```

---

# 💬 Comments

Comments are notes written inside the program.

Python ignores comments while executing the program.

### Single Line Comment

```python
# This is a comment
```

### Multi Line Comment

```python
"""
This is
a multi-line
comment
"""
```

### Advantages

- Improve Readability
- Explain Logic
- Easy Debugging
- Better Documentation

---

# 📦 Variables

A variable is a container used to store data.

### Syntax

```python
variable_name = value
```

### Example

```python
name = "Pushpa"
age = 19
```

---

## Rules of Variables

✔ Start with letter or underscore

✔ Cannot start with number

✔ No spaces

✔ Case Sensitive

---

## Valid Variables

```python
student_name
age
marks
college
```

---

## Invalid Variables

```python
1name
my name
student-name
```

---

# 📊 Data Types

Python supports different data types.

## Integer (int)

Stores whole numbers.

```python
age = 19
```

---

## Float

Stores decimal numbers.

```python
height = 5.4
```

---

## String (str)

Stores text.

```python
name = "Pushpa"
```

---

## Boolean (bool)

Stores True or False.

```python
is_student = True
```

---

## Checking Data Type

```python
age = 19

print(type(age))
```

Output

```
<class 'int'>
```

# ⌨ Taking User Input

The `input()` function is used to take input from the user.

### Syntax

```python
input("Enter Value")
```

---

### Example

```python
name = input("Enter your name: ")

print(name)
```

Output

```
Enter your name: Pushpa

Pushpa
```

---

### Integer Input

```python
age = int(input("Enter Age: "))
```

---

### Float Input

```python
height = float(input("Enter Height: "))
```
