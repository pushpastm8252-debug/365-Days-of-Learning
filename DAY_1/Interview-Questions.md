## Q1. Who developed Python?

Answer:

---

## Q2. In which year was Python released?

Answer:

1991

---

## Q3. What is Python?

Answer:

Python is a high-level, interpreted, object-oriented, and general-purpose programming language.

---

## Q4. Why is Python called an interpreted language?

Answer:

Because Python executes code line by line without compiling the entire program before execution.

---

## Q5. What is the use of print()?

Answer:

The print() function displays output on the screen.

---

## Q6. What is input()?

Answer:

The input() function is used to take input from the user.

---

## Q7. What is a variable?

Answer:

A variable is a container used to store data.

Example

```python
name = "Pushpa"
```

---

## Q8. What are data types?

Answer:

Data types define the type of value stored inside a variable.

Examples

• int

• float

• str

• bool

---

## Q9. Difference between int and float?

Answer

int stores whole numbers.

Example

```python
age = 20
```

float stores decimal numbers.

Example

```python
height = 5.6
```

---

## Q10. Difference between print() and input()?

print()

Displays output.

input()

Takes input from the user.

---

## Q11. What is a comment?

Answer

A comment is ignored by Python and is used for explanation.

Single-line comment

```python
# This is a comment
```

---

## Q12. Why are comments used?

Answer

• Improve readability

• Explain logic

• Debugging

• Documentation
